# dinmukhamed.dev — Personal Portfolio

Single-page portfolio for Dinmukhamed Tynysbay. Plain HTML + CSS + vanilla JS, no build step.

## Deploy to Vercel

1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com) → **Add New Project** → import the repo
3. No build settings needed — Vercel auto-detects static HTML
4. Click **Deploy**

Custom domain: Vercel Dashboard → your project → **Settings → Domains**.

## Local preview

Open `index.html` directly in a browser, or run any static server:

```bash
npx serve .
# or
python3 -m http.server 3000
```
